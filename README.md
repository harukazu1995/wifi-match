# 📶 WiFi Match（スマホアプリ版）

同じWiFiに接続している「アプリを入れた人」同士が、**中央サーバーなしで**お互いを見つけてマッチングするAndroidアプリです。

## しくみ

```
 スマホA ──UDPブロードキャスト「ここにいるよ＋プロフィール」──▶ 同じWiFiの全員
 スマホA ◀──────────── スマホB も同じように発信 ─────────────
 スマホA ──いいね／メッセージ（HTTPで直接）──▶ スマホB
```

- 各スマホが3秒ごとに自分のプロフィールをWiFi内に発信し、受け取った端末の一覧に表示
- いいね・1対1チャット・広場チャットは、相手のスマホへ直接送信
- データは各スマホの中だけに保存。インターネット上のサーバーには一切送らない
- 同じWiFiを離れると相手の一覧から消える（マッチとトーク履歴は残り、また同じWiFiで会えば話せる）

## 機能

| タブ | 内容 |
|---|---|
| みんな | いま同じWiFiにいる利用者。共通の趣味が多い順 |
| マッチ | お互いにいいねした人。タップで1対1チャット |
| 広場 | WiFi内の全員が見られるグループチャット |
| 自分 | プロフィール編集・データ削除 |

安全面：18歳以上の確認、ブロック（お互い非表示）、送信元IPの照合によるなりすまし防止、文字数制限。

## APK を作ってみんなに配る（PC に開発環境は不要）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロード（`.github` フォルダも含める）
2. 自動でビルドが始まる（**Actions** タブで確認、約5〜8分）
3. みんなに配るには、タグ `v1.0.0` を作成（GitHub の **Releases → Draft a new release → タグ v1.0.0 → Publish**）
4. 数分後、Releases ページに `WiFiMatch.apk` が付く。このページのURLを共有すれば、誰でもスマホからダウンロードできます

スマホ側：APKを開く →「提供元不明のアプリ」を許可 → インストール。

### 自分のPCでビルドする場合

```
flutter create --platforms=android --org com.wifimatch --project-name wifi_match .
python3 tool/patch_android.py
flutter build apk --release
```

## 注意

- **公衆WiFi（カフェ・大学・ホテル等）**は端末同士の通信を禁止していることが多く、その場合はお互いが見えません。自宅・オフィス・イベント用ルーター・スマホのテザリングなら動きます
- アプリを開いている間だけ見つけ合えます（バックグラウンドでは発信が止まることがあります）
- **iPhone 版**：iOS でWiFiブロードキャストを使うには Apple の「マルチキャスト通信」特別許可（申請制）と有料の開発者登録が必要なため、今回は Android 版のみです
- Google Play で公開する場合は、マッチングアプリ向けの審査要件（通報機能・年齢確認など）を満たす必要があります
